How it works

A blockchain is a distributed ledger of blocks linked by cryptographic hashes. Each block contains:

  • Index: Position in the chain.
  • Data: The information stored in the block.
  • Previous Hash: The hash of the block before it, creating the "chain".
  • Nonce: A number used to find a hash that meets a specific difficulty (Mining).
  • Hash: The digital fingerprint of the current block.

Changing any data in a block invalidates all subsequent blocks, making the system immutable.
